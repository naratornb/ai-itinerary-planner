# Package planning

Language for contextual recommendations while a creator builds a travel package.

## Language

**Co-pilot turn**:
One creator request and its resulting contextual suggestions in a package conversation.
_Avoid_: Chat session, generated itinerary

**Suggestion feedback**:
A creator's acceptance or dismissal of an individual recommended inventory item.
Acceptance expresses preference and does not add the item to the package.
_Avoid_: Booking, automatic application
